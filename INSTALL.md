# Instalacja SnapSort

1. Otwórz stronę [GitHub Releases](https://github.com/P-Bakowski/SnapSort/releases).
2. Pobierz `SnapSort_v1.0.1.zip` i rozpakuj archiwum albo pobierz sam plik `SnapSort_Setup_v1.0.1.exe`.
3. Uruchom `SnapSort_Setup_v1.0.1.exe`.
4. Wybierz katalog instalacyjny. Domyślnie jest to `Program Files\SnapSort`.
5. Opcjonalnie zaznacz `Utwórz skrót na pulpicie`. Skrót w menu Start jest domyślnie włączony.
6. Rozpocznij instalację i poczekaj na jej zakończenie.
7. Na ekranie końcowym możesz zaznaczyć `Uruchom SnapSort`.
8. Kliknij `Zakończ`.

## Odinstalowanie

Otwórz **Ustawienia Windows > Aplikacje > Zainstalowane aplikacje**, znajdź SnapSort i wybierz **Odinstaluj**. Możesz również użyć skrótu **Odinstaluj SnapSort** w menu Start.
